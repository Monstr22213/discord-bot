# Discord Auth Bot — Верификация + Автороли

Готовый бот для твоего сервера. Делает всю "дичь" из коробки.

### Что умеет:
1.  **🔐 Верификация** — кнопка `Верифицироваться`, выдает роль и открывает доступ к серверу
2.  **🎭 Самовыдача ролей** — панель с кнопками, юзер сам тыкает и получает/снимает роли
3.  **👋 Приветствие** — красивое embed приветствие для новичков
4.  **📜 Логи** — кто зашел/вышел, кто верифицировался, чистки
5.  **🛡️ Модерация** — `/очистка`, `/кик`, `/бан`, `/мут`, `/юзер`, `/сервер`

### Быстрый старт (5 минут):

**1. Создай бота:**
- Иди на https://discord.com/developers/applications -> New Application -> Bot -> Reset Token -> скопируй токен
- Включи все 3 галочки в `Privileged Gateway Intents` (Presence, Server Members, Message Content)
- Во вкладке OAuth2 -> URL Generator выбери `bot` + `applications.commands`, права `Administrator` -> скопируй ссылку и пригласи бота на сервер. **Роль бота должна быть ВЫШЕ ролей которые он выдает!**

**2. Настройка:**
- Скопируй `.env.example` в `.env`
- Вставь `DISCORD_TOKEN`
- Включи режим разработчика в Discord (Настройки -> Расширенные) -> ПКМ по серверу/каналу/роли -> Копировать ID -> вставь в `.env`
  - `VERIFY_ROLE_ID` — какую роль выдавать при верификации (например @Участник)
  - `SELF_ROLES` — список ролей для самовыдачи через запятую (например @Игры, @Аниме, @Музыка)
  - `WELCOME_CHANNEL_ID` и `LOG_CHANNEL_ID` — опционально

**3. Запуск:**
```bash
pip install -r requirements.txt
python bot.py
```

**4. На сервере пропиши:**
- `/верификация` — создаст embed с кнопкой верификации в этом канале
- `/роли` — создаст панель с кнопками ролей

Готово!

### Команды:
- `/верификация [канал]` - панель верификации (только админ)
- `/роли [канал]` - панель ролей (только админ)
- `/очистка <1-100>` - удалить сообщения
- `/кик @юзер [причина]`
- `/бан @юзер [причина]`
- `/мут @юзер <минуты> [причина]`
- `/юзер [@юзер]` - инфа
- `/сервер` - инфа о сервере
